# Sección 5 
# Respuestas Teóricas

A continuación se presentan las respuestas seleccionadas y justificadas para la evaluación teórica:

1. **En Azure, la solución serverless que unifica SQL, Spark y Data Explorer para analítica a gran escala es:**
   * **Respuesta seleccionada:** b) Azure Synapse Analytics (serverless/ dedicated)
   * **Justificación:** Es el servicio unificado de analítica de Microsoft Azure que integra el almacenamiento de datos empresariales y sistemas de Big Data bajo un mismo entorno sin servidor o dedicado.

2. **En Data Factory / Synapse Pipelines, la actividad gráfica para transformaciones a escala sin escribir código es:**
   * **Respuesta seleccionada:** c) Mapping Data Flows
   * **Justificación:** Permite diseñar flujos de transformación de datos de manera visual, los cuales se traducen y ejecutan internamente como trabajos distribuidos sobre clústeres de Spark de forma transparente.

3. **En Spark, la abstracción tolerante a fallos que permite procesamiento en memoria con transformaciones perezosas es:**
   * **Respuesta seleccionada:** d) RDD (Resilient Distributed Dataset)
   * **Justificación:** Representa la colección de datos distribuida y tolerante a fallos básica de Spark, caracterizada por la evaluación perezosa (*lazy evaluation*) de sus operaciones.

4. **En Pandas, para eliminar filas duplicadas en un DataFrame se usa:**
   * **Respuesta seleccionada:** b) df.drop_duplicates()
   * **Justificación:** Es la función nativa provista por la biblioteca Pandas para filtrar y eliminar registros redundantes dentro de una estructura bidimensional de datos.

5. **En Azure Databricks, ¿qué lenguaje se usa con mayor frecuencia para data engineering y notebooks (además de Python)?**
   * **Respuesta seleccionada:** c) Scala
   * **Justificación:** Scala es el lenguaje nativo en el que está implementado Apache Spark, siendo el más adoptado para ingeniería de datos de gran volumen junto con Python.
